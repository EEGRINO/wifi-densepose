# Локализация одного человека по CSI

Страница: `http://127.0.0.1:8080/localization.html`.
Она работает со штатным `nn_pipeline.py` и WebSocket на порту 8765.

Это отдельная экспериментальная локализация по отпечаткам радиоканала.
Камера и веса модели позы не используются. Реальная точность пока не измерена.

## Подтверждённые размеры комнаты

Длинная стена 6,46 м, короткая противоположная 4,04 м, глубина 2,87 м.
Площадь на чертеже 16,8 м². Вход справа, точное положение двери не задано.
Изогнутая стена в интерфейсе приближена четвертью эллипса: это схема,
а не обмерный план. Площадь такой схемы около 17,05 м², поэтому значения
на чертеже и на схеме явно разделены. Места близко к дуге следует сверять на месте.

Начало координат — левый верхний угол схемы.
X идёт вправо вдоль длинной стены, Z вниз по глубине комнаты.
Начальная сетка — 3 столбца × 2 строки. Размеры можно редактировать до записи данных.

## Запуск на Windows

Из каталога `laptop_server`:

```powershell
.\.venv\Scripts\python.exe nn_pipeline.py
```

Во втором терминале, из того же каталога:

```powershell
.\.venv\Scripts\python.exe -m http.server 8080 --bind 127.0.0.1 --directory static
```

Если окружения ещё нет:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Не запускайте второй приёмник на UDP 5555 параллельно.
Обе ESP должны отправлять CSI на текущий IPv4 ПК в сети роутера, UDP 5555.
Интернет для этой страницы не требуется.

## Позиции оборудования

На плане в поле «Щелчок на схеме» выберите роутер, ESP №1 (75BC)
или ESP №2 (46D8). Щелчок внутри комнаты сразу сохраняет положение.
Можно также ввести X/Z в метрах и нажать «Сохранить устройство»;
высота необязательна. Кнопка «Убрать метку» снимает выбранную отметку.

Метки и высоты сохраняются в manifest.json набора данных и восстанавливаются
после перезапуска. Пунктир показывает геометрию заданных соединений,
не измеренное покрытие. Эти координаты документируют расстановку:
они сами по себе не превращают CSI в дальность или триангуляцию.
После начала сбора изменение расстановки блокируется, чтобы не смешивать
записи, сделанные при разных положениях оборудования.
Чтобы выбрать точку человека, переключите поле обратно или нажмите выбор
центра сектора. Метки устройств не заменяют метки обучающих примеров.

## Сбор данных

1. Зафиксируйте положения роутера и двух ESP; больше не перемещайте их.
2. На странице сохраните план комнаты. Выберите центр первого сектора.
3. Выберите «Обучение», задержку 15 с и длительность 20–30 с.
4. Нажмите запись, займите выбранную точку. Оставайтесь в ней до конца
   записи; меняйте направление тела. Не ходите по всей комнате.
5. Запишите каждое место минимум дважды отдельными заходами.
6. Выберите «Пусто» и дважды запишите комнату без людей и животных.
7. Нажмите «Обучить». Минимум для технического старта: две точки
   с двумя записями в каждой и две записи «Пусто». Для покрытия комнаты
   нужны записи во всех интересующих секторах.
8. Отдельно соберите записи с назначением «Независимая проверка».
   Желательно в другой заход, а затем и в другой день.
9. Для проверки поведения между точками обучения выбирайте дополнительные
   реальные координаты и отмечайте их как проверочные.

Отсчёт и запись выполняются на сервере автоматически, а не через чат.
Во время записи никаких разрешений на ПК не требуется.
При разрыве страницы сервер завершит уже запущенную запись.
После перезапуска незавершённая запись не восстанавливается.

## Что показывает результат

Оценивается ближайшее обученное опорное место по сходству CSI;
это ещё не непрерывное измерение координат с сантиметровой точностью.
Сектор выводится по геометрии выбранного места.

Незнакомый сигнал, неоднозначное голосование или отсутствие одной из
зафиксированных радиолиний приводят к «Положение неизвестно»/«Нет данных»,
а не к сохранению последней точки.

Сервер использует отдельные признаки всех линий RUV2: среднюю форму
амплитуд, RSSI, среднюю мощность и временные изменения.
Окно — 1 с, обновление примерно раз в секунду.
Объединение делается по времени приёма ПК, не по аппаратно синхронизированным часам ESP.

Измеряются точность сектора, доля выданных оценок, медианная ошибка
и 90-й процентиль ошибки в метрах, ложное присутствие и пропуски человека.
Ошибка координат считается только для окон с человеком, где выдана точка;
обязательно смотрите и долю таких окон.

Окружность на карте — 90-й процентиль ошибок на проверочных записях,
а не гарантия границы ошибки текущего положения.
Мало проверочных сеансов — недостаточно для вывода об устойчивости модели.

## Хранение и ограничения

Данные хранятся локально в `localization_data/`: отдельные NPZ-сеансы,
описание набора и отчёт JSON. Веса позы и калибровка присутствия не заменяются.
Проверочные записи не используются при подборе масштаба признаков и обучении.
Внутренняя проверка исключает целые сеансы, а не случайные соседние кадры;
порог неизвестного состояния подобран по обучающим сеансам, поэтому
независимую оценку смотрите только в отчёте test.

План блокируется от изменения после появления записей.
При смене комнаты, канала, размещения оборудования или IP приёмников
нужен новый набор: остановите сервер и переименуйте каталог данных,
сохранив его как резервную копию. Автоматического стирания записей нет.

Одна модель предназначена для одного человека в одной комнате.
Несколько людей и животные могут давать неверные результаты.
Смена мебели, дверей и ориентации человека требует проверки устойчивости.
Программные тесты на синтетических данных не подтверждают точность на железе.

## Проверка программы

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Повторные клики в пределах 10 см внутри одного сектора считаются одним опорным местом при обучении. Исходные координаты сеансов сохраняются без изменений. Точки разных секторов не объединяются.


## Текущий классификатор

Используется линейный классификатор с L2-регуляризацией (ridge, alpha=10)
и балансировкой классов. Параметр выбран по внутренней проверке только
обучающих записей. Проверочные записи не участвуют в выборе масштаба,
обучении весов и расчёте порога неизвестного состояния.
Индикатор agreement — преобразованный разрыв двух лучших линейных оценок,
а не вероятность правильного ответа. Состояние неизвестности также
проверяется по расстоянию до обучающих отпечатков.
Предсказанная координата — средняя координата выбранного опорного места,
не непрерывное измерение положения. Для оценки новой версии модели нужны
новые независимые сеансы, желательно в другое время.


## Эксперимент SVM

В блоке обучения можно выбрать SVM RBF и нажать «Обучить по записям».
Это явный отдельный эксперимент, не автоматическое обещание большей точности.
Линейный вариант остаётся доступен. Веса обеих моделей рассчитываются заново
по тем же обучающим записям; исходные NPZ не заменяются.
SVM: C=1, gamma=0.0005, балансировка классов, без predict_proba.
Выбор параметров сделан только по исключению целых обучающих сеансов.
OVR-разрыв оценок используется как индикатор неоднозначности, не как
калиброванная вероятность. После выбора новой модели нужны новые проверочные
сеансы во всех секторах и в пустой комнате.

## Контроль качества приёма

Раздел «Качество приёма» показывает по каждой линии RSSI, шумовой порог,
оценочный SNR и число пакетов в секундном окне; по приёмникам — пропуски
seq, дубликаты, перестановку пакетов и замеченные сбросы счётчика.

Пропуски seq говорят о недоставленных принятых ESP кадрах (UDP/очередь),
но не измеряют количество радиопакетов, которые ESP вообще не смогла принять.
Слабые значения RSSI/низкий SNR и падение частоты не определяют источник
помех. Другие сети и микроволновка могут ухудшать приём, но этот код
не является спектроанализатором и не подавляет их радиосигнал.

Окно блокируется при пропусках >10%, RSSI ниже -85 дБм, достоверном
оценочном SNR ниже 6 дБ, недостатке пакетов/покрытия окна, смене канала
или коротком периоде стабилизации после сброса seq.
Это консервативные инженерные пороги приложения, не паспортные пределы ESP.
SNR вычисляется только если доступно правдоподобное значение noise_floor;
нулевые/неподдерживаемые значения отображаются как отсутствие измерения.
Нормальные показатели не гарантируют чистоту эфира или точность координат.

Повторы и запоздалые пакеты не участвуют в признаках локализации.
Плохие окна не записываются. Если сохранилось менее 80% длительности,
сеанс отклоняется. В новых NPZ сохраняется quality_json с показателями
каждого окна; старые сеансы не переписываются и не получают выдуманную
статистику шума. Формат числовых признаков не изменён.

Для экспериментов используйте фиксированный канал и 20 МГц,
отключайте автоматическую смену канала. Выбор канала требует обследования
эфира на месте: сам по себе номер 1/6/11/13 не гарантирует отсутствие помех.
Не запускайте сканирование каналов одновременно с записью CSI.
После смены канала, размещения или условий RF нужны проверка и, возможно,
новый набор обучения. Роутер не перенастраивается автоматически.

Контроль качества включён в локализацию; основной CSI-экран продолжает
показывать исходный поток для диагностики. Калибровка присутствия не заменяется.

Единичные кадры с некорректным RSSI, RSSI ниже -85 дБм или оценочным SNR ниже 6 дБ не участвуют в признаках. При доле таких кадров выше 10% блокируется всё окно. Движение человека само по себе не является признаком помех и не отбрасывается.


## Контролируемый эксперимент A/B

Кнопка «Новый контроль A/B» создаёт отдельный набор с копией плана
и мест оборудования, без удаления или переноса исходных сеансов.
Исходный набор доступен в списке «Первоначальные записи».
Новый набор хранится в localization_data/experiments/<id>/.
active_dataset.json запоминает выбранный набор после перезапуска.
При переключении модель сбрасывается: нажмите «Обучить», чтобы восстановить её
по записям именно открытого набора. Во время записи переключение запрещено.

Цель контроля — проверить различимость двух удалённых мест и повторяемость.
Это не заявление о достигнутом определении шести секторов.
Точки для текущей комнаты: A=(1.00,0.92), B=(5.35,0.72) м.
Нажмите «Выбрать следующий шаг контроля», затем «Начать запись».
Порядок: Пусто, A, B, A, B, Пусто, A, B.
После восьми обучающих записей обучите SVM.
Далее сделайте новые независимые записи A, B и Пусто.
Перезапуск, перемещение устройств или смена канала посреди серии
нарушают сопоставимость; это нужно проверять отдельным экспериментом.

Для координат человека теперь доступны поля X и Z.
Кнопка «Выбрать по координатам» показывает отметку на плане.
При запуске записи введённые координаты также проверяются и применяются;
пустой комнате соответствует кнопка «Выбрать Пусто», которая очищает поля.

Если внутренняя проверка с исключением целых сеансов не лучше постоянного выбора самого частого класса, модель помечается model_unreliable и не выдаёт точку. Этот минимальный контроль не заменяет независимую оценку и не гарантирует качество прошедшей модели.


## Контрольная модель по RSSI

В списке алгоритмов есть «Ridge — только RSSI (контроль)», команда сервера
localization_train с algorithm=`ridge_rssi`. Используется одно значение RSSI
из каждого сохранённого блока радиолинии. Амплитуды CSI, их мощность и
временные изменения в этой модели не участвуют. Исходные NPZ по-прежнему
содержат полные признаки; эта проекция не меняет формат файлов и не требует
перепрошивки. Масштабирование и веса вычисляются только по обучающим записям,
включая каждый шаг проверки с исключением целой записи.

Этот режим служит контрольным сравнением с полной моделью CSI. Его результат
не подтверждает работоспособность локализации по форме CSI или точные
координаты между обученными местами.

Если проверочная запись уже использовалась для разбора ошибок и разработки
новой модели, её можно перевести в diagnostic командой localization_diagnostic
с session_id. Файл и метка места сохраняются; в таблице появится «Диагностика».
Такие записи не участвуют в обучении и в новой независимой оценке test.
Для проверки новой версии собирают свежие записи с назначением «Независимая проверка».

Дополнительно координаты скрываются, если в отдельной независимой записи
не менее 8 окон и менее половины окон правильно определяют пустую комнату
или сектор человека. Неизвестные ответы считаются неуспехом.
Это технический предохранитель от показа заведомо неработающей модели,
а не гарантия точности при прохождении контроля.


## Изменение формы CSI относительно пустой комнаты

Алгоритм «Ridge — изменение CSI от пустой комнаты» (ridge_csi_change)
использует по одному признаку на радиолинию: среднеквадратичное отклонение
52 нормированных амплитуд от обучающего эталона пустой комнаты.
Это величина изменения формы CSI, а не расстояние в метрах и не RSSI.

Эталон — медиана отдельных медиан обучающих записей «Пусто».
При исключении записи для проверки эталон, масштабирование и веса
вычисляются заново только по оставшимся обучающим записям.
Проверочные и диагностические записи в эталон не включаются.
Исходные признаки и NPZ остаются прежними. После изменения расстановки
или условий радиообмена нужна проверка пригодности эталона.

Серия, уже использованная для выбора признаков и модели, является данными
разработки. Её можно скопировать в отдельный обучающий набор с сохранением
источника каждой записи; исходный набор не изменяют. Для независимой
оценки после выбора модели нужны новые записи.


## Сырые пакеты диагностической записи

В режиме «Диагностика — без обучения» сервер дополнительно сохраняет
исходные UDP-пакеты рядом с NPZ в файле с тем же ID и расширением .ruvrec.
Формат совместим с csi_record.read_recording() и существующим воспроизведением.
В файле есть назначение, метка места, расстановка, время и исходный RUV2
с I/Q, RSSI, шумом, номером кадра и временем ESP. Время записи пакета —
время приёма на ПК; аппаратной синхронизации между ESP это не создаёт.

Сохраняются только пакеты выбранных линий в интервале измерения, без отсчёта.
Пакеты записываются до фильтрации качества, поэтому доступны также дубли
и плохие RF-кадры. Ограничение — 100000 пакетов на сеанс; превышение явно
отмечается в raw_dropped_count. Обычные обучающие и проверочные сеансы
не меняются. Отменённые и не прошедшие минимум окон записи сырых файлов
не создают. Ранее записанные NPZ не содержат потерянные исходные пакеты:
восстановить их задним числом нельзя.
