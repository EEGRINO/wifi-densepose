Калибровка и запись

Запишите фон пустой комнаты и минимум три обучающие точки. Выйдите из комнаты или займите точку во время отсчёта.

Обучение и проверка

Обучение и проверка запускаются по сохранённым записям. Для независимой проверки запишите хотя бы одну отдельную точку и пустую комнату.

«В отложенных блоках» — проверка внутри записанных сеансов. Для измерения погрешности используйте отдельные контрольные точки.
